# Actualiser le parcours

Lis le [routage du dépôt](../../../AGENTS.md), la [page Parcours](../../../pages/parcours.qmd), la [chronologie](../../../pages/cours.qmd) et le [registre des traces](../../sources/traces.md).

1. Lis en lecture seule le bilan, le code pertinent et l’entrée IA de la semaine concernée dans le portfolio. Un laboratoire commun peut couvrir deux modules. Indique son classement réel sans compter deux semaines terminées.
2. Distingue le travail terminé selon Arthur, les contrôles rapportés dans le bilan et les contrôles refaits pendant la séance. Des tests qui révèlent les défauts d’une fonction peuvent être le résultat attendu d’un exercice.
3. Propose les faits et les pages à modifier avant toute écriture. Attends la validation d’Arthur, sauf si les changements proposés ont déjà été approuvés dans la séance.
4. Actualise les cartes de la page du cours avec l’activité et les thèmes pertinents. Pour un extrait, vérifie sa source et indique les prérequis. Les semaines documentaires peuvent montrer une trace à la place d’un code absent. Vérifie les filtres après ajout. Dans le parcours, relie une situation concrète à une démarche et à un apprentissage documenté. Évite de recopier le bilan complet ou d’attribuer une autonomie non établie.
5. Actualise le registre des traces, le README si ses repères changent, la progression, l’AI-log et la déclaration publique pour les usages significatifs.
6. Suis [rediger-quarto](../rediger-quarto/SKILL.md) pour le rendu et le contrôle des liens. Conserve les anciennes adresses de pages.

Le résultat doit permettre de retrouver la preuve d’une affirmation et de distinguer une production consultée d’une analyse réexécutée.
