1. Lis `atelier/sources/traces.md` et ouvre seulement les sources nécessaires. Travaille en lecture seule sur les dépôts voisins.
2. Pour GitHub Actions, identifie le document `GitAction` demandé et distingue son récit du workflow en vigueur. Sépare la validation documentée d’une exécution vérifiée. Pour le Défi 2, distingue les résultats rapportés d’un calcul reproduit.
3. Dans la fiche de traces, indique le dépôt, le chemin, la section ou le commit pertinent, le fait établi et les limites. Étiquette les éléments à vérifier avant publication.
4. Transmets une synthèse exploitable à l’agent Quarto. Garde les rapports, données et énoncés dans leurs dépôts d’origine.
